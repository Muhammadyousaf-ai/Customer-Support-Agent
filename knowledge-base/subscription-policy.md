# Free plan
<!-- tiers: free; contracts: monthly -->

The Free plan costs nothing and includes one project, 1,000 API requests per day and community support. It has no invoices, no priority support and no contract. Free accounts can upgrade to Basic, Pro or Enterprise at any time.

# Basic plan
<!-- tiers: basic; contracts: all -->

The Basic plan costs $19 per month or $190 per year. It includes five projects, 10,000 API requests per day, email support and invoice history. Basic does not include priority support, webhooks or team seats.

# Pro plan
<!-- tiers: pro; contracts: all -->

The Pro plan costs $49 per month or $490 per year. It includes unlimited projects, 100,000 API requests per day, webhooks, up to 10 team seats and priority support with a four hour response target.

# Enterprise plan
<!-- tiers: enterprise; contracts: all -->

Enterprise pricing is defined in the signed contract; the standard rate is $199 per month. It includes negotiated API limits, unlimited team seats, single sign-on, a dedicated account manager and a one hour response target for urgent issues.

# Upgrades and downgrades
<!-- tiers: all; contracts: all -->

Upgrades take effect immediately and the price difference is prorated for the rest of the billing period. Downgrades take effect at the next billing date and the current plan features stay available until then. Moving between billing periods, for example monthly to annual, is processed at the next renewal.
